# Slasher roguelike starter
![SlasherEnemyFollowingBehavior_mIsForMenace](https://github.com/user-attachments/assets/3f085f75-1290-4241-950b-0850d4e09f8b)

Version 0.2:
Enemies now either follow, flee from, or ignore the player based on their goal. Only following is implemented currently. (Ignoring is implicitly implemented via GoalType.Empty)
*Rudimentary enemy spawn added for testing.

Version 0.1:
*various folders and classes added to the projects, to ensure future compatibility with Biome varibility etc. 
This repository contains the basics of a roguelike with improved terrain generation:
- [Class library](https://github.com/xnafan/Slasher.GameLibrary/tree/master/Slasher.GameLibrary) (Tiletypes, Maps)
- [Console](https://github.com/xnafan/Slasher.GameLibrary/tree/master/Slasher.GameConsole) (visualizer of map)
